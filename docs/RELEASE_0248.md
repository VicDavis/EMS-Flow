# EMS Flow · Alpha Build 0248

Windows x64. Включены изменения 0247 и 0248 после опубликованной версии 0246.

## Окно и меню

- Выход из полного экрана центрирует окно на текущем мониторе, с прозрачностью и без неё.
- Вверху оконного режима добавлена область перетаскивания, доступная и в прозрачном режиме.
- Компактное меню основных разделов заменено цветными выдвижными ярлыками, как в настройках. В прозрачном режиме расположение зеркальное.
- Исправлены цвета ярлыков в прозрачных настройках.
- Убрана постоянная плашка предпросмотра из поиска; сохранение маршрута пациента не изменено.

## Фидбэк и рекрутинг

- «Жалобы» переименованы в «Фидбэк». Новая форма: https://forms.docossum.com/seattle-ems-feedback.
- Реплика — «Обратная связь и отзыв» со ссылкой. Меню уплотнено, поясняющая надпись удалена.
- Внешние ссылки открываются в браузере по умолчанию; EMS Flow уступает передний план, оставаясь на панели задач.
- Переключатель «ДБ» больше не показывает расшифровку и даты; включение и выключение маршрута сохранены.

## Установка

Закройте EMS Flow и установите обновление поверх прежней версии. Удалять сохранения не нужно. Перед обновлением можно экспортировать настройки. Portable ZIP работает без установки.
