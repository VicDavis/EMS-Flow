# EMS Flow Alpha Build 0244

Обновление после публичной Alpha Build 0240: изменения сборок 0241–0244. Windows x64, EMS сервера Seattle в Majestic RP.

> Ранняя тестовая альфа. Прямой ввод текста в GTA изменён в 0244 и требует игровой приёмки. Автоматические тесты не подтверждают публикацию текста игровым чатом. Автоотправка выключена до явного включения.

## Игроки и массовый мут

- Независимая отметка «Мут» рядом с «Друг / Враг». Для команды требуется статик до шести цифр.
- В таблице отображается перечёркнутый динамик. Пустые фракция и статус больше не создают плашки с прочерком.
- Кнопка динамика рядом с «Игроки» показывает число отмеченных игроков и последовательно передаёт `/vmute статик`.
- Повторяющиеся статики исключаются; реплики и команды мута не смешиваются. Повторный клик во время обработки отменяет остаток очереди.
- Ошибка или потеря фокуса останавливает обработку без повторов. Результат мута на сервере приложение не читает; не запускайте список повторно без необходимости.

## Прозрачный режим

- Логотип и главное меню перенесены вправо. При переключении режима элементы плавно уходят за край и появляются с другой стороны.
- Компактное меню CD/HAD/PSID/DI/IN расположено ниже основного меню у правого края. Без наведения оно задвинуто, при наведении раскрывается. Исправлено растягивание панели.
- «Новый пациент / Новый кандидат» смещена ниже и правее для уменьшения пересечений с игровым HUD.
- Хотбар прижат вправо. Счёт, телефон и Discord стоят в одной строке слева от отката. Интервалы уменьшены до 3 CSS px; кнопка таймера +30 скрыта только в оверлее.
- Памятки, подсказки хоткеев и всплывающие подписи временно скрыты. После выключения прозрачности возвращаются без изменения сохранённых настроек. Уведомления об ошибках и действиях остаются видимыми.

## Реплики и документация

- Перетаскивание переведено на события указателя. Сохранены проекция полного размера, перенос между страницами и отмена Escape.
- После завершения переноса не выполняется случайное копирование или автоотправка.
- Подпись автора отображается в документации и настройках, где нет хотбара.
- Встроенная документация сокращена и актуализирована. README репозитория обновлён под текущую сборку.

## Автоотправка

- Вместо Clipboard/Ctrl+V используется прямой Unicode-ввод: T → текст → Enter → ё.
- Между этапами добавлены паузы; физические клавиши нажимаются и отпускаются раздельно.
- Быстрые клики остаются в ограниченной последовательной очереди.
- Ошибка системного ввода до Enter останавливает последовательность. Автоматических повторов нет.
- Выключение автоотправки передаёт отмену модулю ввода, чтобы он успел отпустить свои нажатые клавиши.

Причина пустого чата в прежнем алгоритме могла быть связана с коротким ожиданием и мгновенным пакетом Ctrl+V. Это гипотеза по коду, а не подтверждённая трассировкой GTA причина. Windows подтверждает приём событий, но не появление текста в игре. Начните проверку с одной короткой реплики при закрытом чате; при сбое отключите автоотправку.

## Проверки и известные ограничения

Пройдены проверки исходников и состава пакета, FIFO/отмены/ошибок автоотправки, точного Unicode-текста, последовательности массового мута, управления окном, ЛКМ и изолированного Electron-интерфейса при двух размерах окна. Упакованные файлы и SHA-256 проверены.

Реальный ввод в GTA во время тестов не выполнялся. Работа поверх игры и на системе тестера требует проверки. Ранее отмеченные проблемы выделения текста в desktop-редакторах и Alt+Tab после Alt+D не объявляются окончательно устранёнными.

## Установка

Закройте EMS Flow и установите новую версию поверх предыдущей в ту же папку приложения. Удалять сохранения не нужно. Portable обновляется заменой файла при закрытом приложении.

- `EMS.Flow.Alpha.Setup.Build.0244.exe` — установщик.
- `EMS.Flow.Alpha.Portable.Build.0244.zip` — портативная версия.
- `SHA256SUMS.txt` — контрольные суммы.

Архивы Source code не являются приложением. Сборка не подписана Authenticode; Windows может показать предупреждение SmartScreen.
