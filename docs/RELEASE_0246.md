# EMS Flow · Alpha Build 0246

Windows x64. Обновление включает изменения 0245 и 0246 после опубликованной версии 0244.

## Реплики и звук

- Палитра из 14 оттенков: семь ярких и семь приглушённых. Цвет сохраняется вместе с плиткой и входит в экспорт настроек.
- Enter в редакторе сохраняет без подтверждения. В диалоге Enter сохраняет, Escape отменяет изменения.
- Сердцебиение только при запуске: переходы в хирургию и ПМП больше не воспроизводят его.

## Рекрутинг, реестры и оверлей

- Переключатель DB — «День блата»: судимости → внешний вид → документы → Discord → оформление. Обычный маршрут сохранён отдельно.
- Пропуска: фильтр «Скрыть недействительные»; дата «До» включительна, последний день остаётся действующим.
- В настройках прозрачного режима главное меню раскрывается зеркально справа.
- Реестр игроков показывает целые строки; устранены мешающие выделению текста события мыши и перехват фокуса.

## Автоотправка

- Строка передаётся одним пакетом, без побуквенных пауз.
- «Откат мисклик» отправляется в игровой чат при включённой автоотправке.
- Автоотправка включена по умолчанию; ручное выключение сохраняется.

## Установка

Закройте EMS Flow и установите обновление поверх прежней версии. Удалять сохранения не нужно. Перед обновлением рекомендуется экспортировать настройки. Portable ZIP работает без установки.
