## Что нового после 0240

- Отметка «Мут» в личном реестре и последовательная отправка `/vmute статик` для отмеченных игроков.
- Исправления перетаскивания реплик: проекция полного размера, отмена Escape, перенос между страницами без случайного копирования.
- Новая компоновка оверлея: главное меню справа, компактный хотбар, меню отделов у правого края ниже основного меню, раскрытие при наведении.
- Памятки и подсказки временно скрываются в прозрачном режиме, не изменяя настройки обычного режима.
- Автоотправка использует прямой Unicode-ввод вместо Ctrl+V; добавлены паузы между этапами и корректная отмена.
- Убраны пустые плашки реестра, подпись автора перенесена на страницы без хотбара, обновлена встроенная документация.

[Полное описание изменений 0241–0244](docs/RELEASE_0244.md).

## Возможности

- Пошаговые маршруты вакцинации, справок, хирургии и рекрутинга Department of Internship.
- Готовые реплики, копирование отдельных предложений и сборка фразы из нескольких плиток.
- Собственные страницы реплик: редактирование, размеры плиток и перетаскивание.
- Личный реестр игроков: имя, статик, фракция, заметки, «Друг» / «Враг» и независимая отметка «Мут».
- Пропуска EMS, заявления, жалобы, запись на приём и быстрый таймер.
- Поиск по приложению, настройки интерфейса, звуков, фона и анимаций.
- Прозрачный оверлей, показ поверх игры и экспериментальная автоотправка в игровой чат.

EMS Flow — игровая шпаргалка и помощник по маршрутам, а не источник медицинских рекомендаций для реальной жизни.

## Установка и обновление

### Установщик

1. Закройте EMS Flow.
2. Скачайте `EMS.Flow.Alpha.Setup.Build.0244.exe`.
3. Установите поверх прежней версии в ту же папку приложения.
4. Сохранения удалять не нужно. Перед обновлением можно экспортировать настройки в приложении.

Не устанавливайте приложение в папку с исходным проектом. Выделите для него отдельный каталог.

### Портативная версия

1. Скачайте `EMS.Flow.Alpha.Portable.Build.0244.zip`.
2. Распакуйте и запустите EXE из архива.
3. При обновлении закройте приложение и замените portable-файл новой версией.

Обе редакции содержат необходимые компоненты. Установленная версия поддерживает обновления через GitHub; режим выбирается в настройках. Portable и HTML обновляются вручную.

Сборка не подписана сертификатом Authenticode: Windows SmartScreen может показать предупреждение о неизвестном издателе.

## Управление

| Действие | Управление |
| --- | --- |
| Показать EMS Flow поверх текущего окна / свернуть | Alt+D |
| Включить / выключить прозрачный оверлей | Alt+O |
| Переключить полный экран | F11; вне текстовых полей также F |
| Редактировать плитку реплики | Тройной ПКМ |
| Переместить плитку | Зажать ЛКМ и перетащить |
| Отменить перенос | Escape |
| Удалить текущую пустую страницу реплик | Delete вне редактора |
| Сохранить карточку игрока | Ctrl+Enter |
| Открыть документацию | Нажать логотип EMS Flow |

Alt+D не должен удалять значок с панели задач. В оверлее элементы EMS Flow принимают ЛКМ, свободное пространство предназначено для приложения под ним. Для GTA рекомендуется оконный или безрамочный полноэкранный режим.

## Автоотправка и массовый мут

1. Оставьте чат GTA закрытым.
2. Включите «Автоотправка» в хотбаре Windows-приложения.
3. Нажмите реплику: приложение передаст T → текст → Enter → ё.
4. Быстрые клики попадут в очередь. Не печатайте вручную, пока она выполняется.
5. При ошибке очередь останавливается без автоматических повторов. Если ввод работает неверно, выключите автоотправку и используйте ручное копирование.

В режиме автоотправки наборная фраза и таймлайн раздела «Реплики» отключены: отправляется каждая выбранная плитка отдельно. После запуска автоотправка выключена до явного включения.

Для массового мута укажите статик игрока, включите «Мут» в карточке и нажмите перечёркнутый динамик рядом с «Игроки». Команды отправляются последовательно. Повторное нажатие во время обработки останавливает оставшуюся очередь. Приложение не читает серверный результат: не повторяйте запуск без необходимости.

**Ограничения:** прямой ввод 0244 требует игровой приёмки, в том числе на системе тестера с пустым чатом. Проблемы выделения текста в desktop-редакторах и поведения Alt+Tab после Alt+D не объявляются окончательно исправленными.

## Данные и приватность

Настройки и личный реестр хранятся в профиле пользователя Windows: `%APPDATA%\ems-flow-desktop`. Экспорт может содержать личные заметки — не передавайте его посторонним.

Удаление этой папки сбрасывает настройки и локальные данные; для обычного обновления это не требуется. Проверка обновлений обращается к GitHub и управляется в настройках. Автоотправка и массовый мут передают выбранный текст/команды в игру по действию пользователя.
