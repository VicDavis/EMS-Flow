## Зачем нужен EMS Flow

Главная задача EMS Flow - дать сотруднику готовую игровую реплику или отыгровку за несколько секунд. Пользователю не нужно набирать длинный текст вручную, открывать отдельный документ, искать нужный абзац, выделять его мышкой и нажимать `Ctrl+C`. EMS Flow ведёт по рабочему маршруту и позволяет скопировать подходящую фразу одним кликом, после чего её остаётся вставить в игровой чат.

Во многих ситуациях это быстрее даже живого голосового ответа. Особенно полезен такой подход людям, которые не могут или не хотят пользоваться голосовой связью: основные рабочие действия EMS можно полноценно отыгрывать через текстовый чат без лишней задержки.

EMS Flow также помогает освоиться на новой должности. Не все алгоритмы, регламенты и последовательности действий запоминаются сразу. Ассистент позволяет самостоятельно пройти их на практике и меньше зависеть от постоянных подсказок более опытного игрока.

Для опытных сотрудников EMS Flow остаётся быстрой шпаргалкой. Например, хирургические маршруты содержат много этапов, формулировок и справочной информации, которую трудно постоянно держать в памяти.

## Что умеет EMS Flow

- ведёт пользователя по пошаговым маршрутам и предлагает подходящую следующую реплику;
- копирует готовую фразу или отдельные части сложной реплики одним кликом;
- собирает несколько выбранных фрагментов в одну естественную фразу в буфере обмена;
- помогает оформлять и обновлять медицинские справки;
- содержит сценарии вакцинации, хирургии и экзаменационной операции;
- предоставляет готовые реплики для общих ситуаций и ПМП;
- ищет реплики, маршруты, подсказки и цены по всему приложению;
- сохраняет незавершённый маршрут пациента и позволяет восстановить его после сброса;
- поддерживает настраиваемые горячие клавиши, полноэкранный режим и показ поверх игры;
- содержит быстрый таймер, настройки интерфейса, звуков и производительности.

## Установка

### Установщик

1. Закройте ранее запущенный EMS Flow.
2. Скачайте `EMS.Flow.Alpha.Setup.Build.0192.exe`.
3. Запустите установщик и выберите каталог установки.
4. Новую сборку можно устанавливать поверх предыдущей. Пользовательские настройки сохраняются.

### Портативная версия

1. Скачайте `EMS.Flow.Alpha.Portable.Build.0192.zip`.
2. Распакуйте архив в отдельную папку.
3. Запустите находящийся внутри EXE-файл.

Обе редакции автономны: необходимые компоненты уже включены. Сборка предназначена для Windows x64.

## Предупреждение Windows SmartScreen

Приложение пока не подписано платным сертификатом Authenticode, поэтому Windows может показать предупреждение о неизвестном издателе.
